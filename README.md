# 🔐 Login Tela

Interface de login desenvolvida como projeto de estudo em desenvolvimento web, com foco na construção de páginas, estilização de elementos e organização visual de formulários.

O projeto tem como objetivo praticar conceitos fundamentais de desenvolvimento front-end, criando uma interface de autenticação simples e intuitiva.

## 🎯 Objetivo do projeto

Desenvolver uma tela de login para aprimorar conhecimentos em desenvolvimento web, explorando a estruturação de páginas e a personalização de interfaces utilizando tecnologias fundamentais da web.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação dos elementos da página.
- **CSS3:** estilização, cores, espaçamentos e organização visual.

## ✨ Características

- Interface de login.
- Organização de campos de entrada.
- Estilização personalizada.
- Estrutura simples e organizada.
- Prática de conceitos fundamentais de HTML e CSS.

## 📂 Estrutura do projeto

```text
login-tela/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/AntenorSantos/login-tela.git
```

2. Acesse a pasta:

```bash
cd login-tela
```

3. Abra o arquivo `index.html` no navegador.

Você também pode utilizar o Visual Studio Code com a extensão Live Server.
